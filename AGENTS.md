# ui-sdk

Before using ui-sdk, follow the ui-sdk skill if it is installed and read `site/node_modules/@ui-sdk/web/docs/llms.txt`.

To build a new component, also search `site/node_modules/@ui-sdk/web/docs/core.md` by heading and read `rendering.md` next to it.

Import each component entry, such as `@ui-sdk/web/dialog`, from an Astro client `<script>` to register its tags in the browser.
